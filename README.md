# yardsaleearlybird.com

Marketing site for Yard Sale Early Bird. Plain static HTML/CSS, no build step. Hosted on GitHub Pages at yardsaleearlybird.com (see CNAME).

- `index.html` homepage, `style.css` styles, `assets/` artwork
- `privacy/`, `terms/` legal pages; `go/` redirects to the web app
- Preview locally: `python3 -m http.server 8000`, then open http://localhost:8000

Preserve the cream/orange/espresso brand, the bird illustrations, and approved copy unless a change is requested.
